# Agent Skills Library

Общая библиотека переносимых Agent Skills.

## Установленные скиллы

| Скилл | Версия | Источник | Зафиксированный коммит |
|---|---:|---|---|
| `video` | `0.7.1` | `guimatheus92/mcp-video-analyzer` | `13b4dfa25399a0f5435c3396cdd810f5d9364ed6` |

Файл скилла: [`skills/video/SKILL.md`](skills/video/SKILL.md).

### Установка оригинальной версии

```bash
npx skills add guimatheus92/mcp-video-analyzer
```

Дополнительно для YouTube, Instagram, TikTok, Vimeo и других платформ:

```bash
pip install yt-dlp
```

Требуется Node.js 18 или новее.
